---
title: C++
description: Subscribe to pose/image and control VIO from C++.
---

Install from GitHub:

```bash
git clone https://github.com/asadm/mighty-protocol.git
```

C++ entry points:
- `cpp/mighty_sdk.h`
- `cpp/mighty_protocol.h`

Minimal usage:

```cpp
#include <iostream>
#include <memory>
#include "cpp/mighty_sdk.h"

int main() {
  using namespace mighty_protocol::sdk;

  auto device = std::make_shared<MightyWebDevice>();
  MightyClient client(device);

  auto pose_sub = client.on_pose([](const PoseFrame& p) {
    (void)p;
  });

  auto img_sub = client.on_image([](const ImageFrame& f) {
    if (f.kind == ImageFrame::Kind::kJpeg && f.jpeg) {
      // JPEG stays compressed until the application needs pixels.
      std::cout << "jpeg bytes=" << f.jpeg->data.size() << '\n';
    } else {
      std::cout << "raw " << f.left.width << "x" << f.left.height << '\n';
    }
  });

  auto event_sub = client.on_event([](const DeviceEvent& event) {
    if (event.kind == "loop_closure") {
      // Parse event.json with your application's JSON library.
    }
  });

  client.connect();
  client.set_loop_closure_enabled(true);
  client.start_vio();
  client.disconnect();
  return 0;
}
```

Applications using OpenCV can include `cpp/sdk/mighty_opencv.h` and call
`opencv::decode_image_to_bgr(...)` for either JPEG or RAW events. Link OpenCV
`core`, `imgcodecs`, and `imgproc`; the core protocol SDK itself remains
header-only and does not require OpenCV.
