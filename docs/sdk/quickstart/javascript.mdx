---
title: JavaScript
description: Connect and stream pose/image in web or Node ESM.
---

Install from GitHub:

```bash
npm install https://github.com/asadm/mighty-protocol
```

Minimal usage:

```js
import { MightyWebDevice, MightyClient, decodeImageToRgb } from "mighty-protocol";

const device = new MightyWebDevice();
const client = new MightyClient(device, { autoReconnect: true, reconnectDelayMs: 500 });

client.onPose((pose) => console.log("pose", pose.positionM, pose.confidence));
client.onEvent((event) => {
  if (event.kind === "loop_closure") {
    console.log("loop closed", event.data);
  }
});
client.onImage(async (img) => {
  const decoded = await decodeImageToRgb(img);
  console.log("image", img.kind, decoded?.width, decoded?.height);
});
client.onError((e) => console.error(e));

await client.connect();
await client.setLoopClosureEnabled(true);
await client.startVio();
```

`decodeImageToRgb` accepts both `kind: "jpg"` and `kind: "raw"`. In Node,
where browser image APIs are unavailable, pass a `jpegDecoder` to
`decodeImageToRgb` or to the `MightyClient` options; the Node examples use
`jpeg-js`.
